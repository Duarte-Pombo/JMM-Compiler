# Java-- Compiler

A compiler for **Java--**, a subset of Java, developed for the Compilers course (2026) at FEUP.
It translates Java-- source code into JVM bytecode through a multi-stage pipeline:

```
Java-- source → AST → Semantic Analysis → Optimizations → OLLIR → Register Allocation → Jasmin → .class
```

## Implemented Extensions

All proposed extensions are implemented. From OLLIR generation onwards, we gave less attention to edge cases and error handling for **Local Static Methods** and **Multidimensional Arrays**, since the maximum grade was already reachable through the other extensions in their categories.

## Register Allocation: Known Issue and Fix

The handling of the maximum number of registers with the `-r` flag has a known ambiguity. We could not determine the intended behavior from the specification or get clarification, so:

- **`main` branch and `cp3` tag:** original implementation, kept as submitted.
- **`fix/regAlloc` branch:** our proposed fix. The register limit is the `-r` value **plus** the temporary variables introduced for branch conditions. The merge request is intentionally left open.

## Repository Structure

| Folder | Description |
|--------|-------------|
| `src/` | Compiler source code |
| `test/` | Our own tests |
| `test-public/` | Public tests provided by the course (do not modify) |
| `libs/` | Required libraries (JAR) |
| `libs-jmm/` | Java classes importable from Java-- code (`java/` sources, `compiled/` output generated by the build) |

## Build and Usage

```bash
./gradlew build
./gradlew run --args="<path/to/File.jmm> <flags>"
./gradlew test
```

Supported flags: `-r=<N>` (register limit), `<other flags, e.g. -o>`
